# Chapter 13. A Philosophy of Streaming Systems

## One-sentence thesis

Correct systems treat app logic as auditable derivation and verify end-to-end integrity.

## Digested claims

- Application code is a derivation function.
- Derived data vs 2PC: idempotent logs vs atomic commit.
- Trust but verify; design for auditability.
- End-to-end argument: local DB strength does not stop bad writers.
