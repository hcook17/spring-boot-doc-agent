# ADR S-STF-F — OpenHands sandbox deferred

**Status:** Accepted · **Date:** 2026-08-08

**Decision:** v1 Verify runs process-local under existing hooks (`deny_text_search`, `deny_raw_network`). OpenHands-style ActionExecutionServer sandbox is deferred until implement agents expand shell blast radius.

**Rationale:** Weight vs benefit for a documentation CLI; containment for query MCP is the sharper P0.
