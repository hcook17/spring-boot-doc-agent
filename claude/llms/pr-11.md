# PR #11 — Add this repo's first CI workflow and a claude/llms/ meta-verification script

## Summary

Closes `claude/steering-prompts/07-ci-scaffold-task-prompt.md` and `CONSTRAINTS.md`'s "no CI/CD" and "`claude/llms/` meta-drift" gaps. Adds `scripts/verify_llms_docs.py` (mechanically re-runs every `git`/`gh` command documented in `claude/llms/pr-*.md`, judged by exit code with a narrow "no/empty output expected" override; the `git worktree add && cd && <rest>; cd - && git worktree remove` shape is decomposed into explicit add/run/remove-in-`finally` steps rather than trusted as one shell string, since its own exit code would otherwise reflect the trailing cleanup rather than `<rest>`) and `scripts/test_verify_llms_docs.py` (17 unit tests, no live git/gh calls). Adds `.github/workflows/ci.yml`, this repo's first CI file — runs the four pre-existing suites plus the two new ones on `pull_request`/`push` to `main`, with `fetch-depth: 0` (most `verify_llms_docs.py` commands read old commit SHAs via `git show <sha>:path`, unreachable on a shallow clone) and `ast-grep` installed via `pip install ast-grep-cli`. Also fixes live drift found while building this: `claude/llms/pr-8.md` and `README.md` both still said PR #8 was open after it had actually merged (`a0acc76`) — repinned all six of `pr-8.md`'s commands to the merge commit.
