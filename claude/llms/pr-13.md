# PR #13 — Add semantic-pipeline-eval and capacity-preflight skills, plus a maturity assessment

## Summary

Adds two new skills closing gaps this repo's own docs already named but never addressed: `skills/semantic-pipeline-eval/` (a semantic/hallucination-detection layer on top of `test_pipeline_stages.py`'s mechanical-only checks — samples `[Evidenced]` claims for truthfulness, flags unmatched `[Confirmed]` tags and Mermaid diagram malformation via `scripts/semantic_eval_helpers.py`'s mechanical pre-pass, checks for cross-doc/cross-diagram contradiction, and routes findings through a two-lane human sign-off) and `skills/capacity-preflight/` (turns this plugin's stated-but-unmeasured scale assumptions into a concrete per-repo number via `scripts/capacity_preflight.py`, which imports rather than reimplements `partition_repo.py`'s/`spring_signal_scan.py`'s own logic). Adds `MATURITY_ASSESSMENT.md`, an evidence-grounded maturity scorecard, drift-from-modern-practice analysis, and adoption gate checklist, which also corrects a stale doc/reality drift found along the way: `CONSTRAINTS.md`/`STATUS.md` both still said the license was `UNLICENSED`; `.claude-plugin/plugin.json` actually says `MIT`. Wires the two new test suites into `.github/workflows/ci.yml`, cross-links the new material from `README.md`/`STATUS.md`, and appends a `claude/session-log.md` entry per this repo's own convention — including an honest note about a scope gap (an "undefined node reference" Mermaid check named during planning but missing from the first implementation) caught and fixed mid-session rather than left silently narrowed.

Pinned below to `3254d67` — the commit containing all of the above. (A follow-up commit on this same branch adds this file plus a `claude/tool-quirks.md` entry about GitHub's web UI being unreliable for fetch-based PR review; that follow-up commit isn't itself covered by the claims below, since a file can't meaningfully verify its own existence.)
