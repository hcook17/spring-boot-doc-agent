# PR #31 — Correct the mirror-back scope, and finish the mirror-back

## Summary

Four commits, all documentation, on one thread: **what is actually mirrored between this repo and its attached Claude project, and which claims about that had gone stale.**

1. **`702171f` — correct the mirror-back scope.** `00-shared-research-standards.md` claimed prompts `01` through `12` were all mirrored from the Claude project. False for six of them, and self-inflicted: PR #29 widened the original, correct `01`–`05` during a docs sweep without checking what the project contains. Corrected to the real three-way split — `00`–`06` have a canonical project copy, `07`–`09` were authored in this repo, `10`–`12` were authored outside the project and landed here in `5bd750b`. `CLAUDE.md` carried the same over-broad claim in two places and is scoped to match. The corrected paragraph says it was wrong and why, rather than quietly reading as if it had always been right — this repo has committed the "prose winning over reality" anti-pattern its own maturation plan tracks, and this was another instance.

2. **`4dc182c` — record the mirror-back manifest.** A per-prompt table of what needed syncing back to the project.

3. **`d2b42ec` — annotate the maturation plan's stale Phase-0 items.** `claude/10-architecture-maturation-plan.md` referenced `PORTING.md`, `scripts/local_ci.sh`, `.gitattributes`, `claude/adr/` and others in present tense ("see `PORTING.md`") when none of them exist — they are things the plan *creates*. Now stated as deliverables, so a reader stops hunting for files that were never written.

4. **`5dc662e` — execute the mirror-back, and replace inference with a content diff.** The manifest from `4dc182c` inferred "needs overwrite" from **commit counts since the import**, which is a proxy for divergence rather than the fact, and it was wrong in two rows. Diffing every project copy against every historical revision of its repo counterpart showed: `02` was already byte-identical and needed no write at all; `05` was two revisions behind, not one. `00`, `01` and `05` matched *no* repo revision, because the import commit `8bb2404` rewrote them rather than copying them. No project copy holds an edit that is not an ancestor of the repo file or the pre-import original — so the two sides had not forked, and the overwrite was safe. All six executed and verified by read-back.

   The manifest table is **corrected in place** rather than annotated as superseded: `4dc182c` has not merged, so there was no shipped text to supersede, and leaving a wrong table standing under a warning label is worse than fixing the two rows. Its column basis changed from commit counts to the content diff, which is the actual lesson.

   This commit also corrects `06-wiredrift-check-task-prompt.md`'s `status:` frontmatter, stale since PR #3 and flagged three separate times in `claude/session-log.md` without being fixed, and adds its missing final newline — it was the only file under `claude/steering-prompts/` without one.

No code changed. Full suite 236 passing, 6 intentional skips — unchanged, as expected for a documentation-only PR.
