# PR #31 — Correct the mirror-back scope, and annotate the maturation plan's stale items

> **Corrected 2026-07-25.** An earlier version of this file described PR #31 as **four** commits, the fourth being `5dc662e` ("execute the mirror-back"). That is wrong: #31 merged at `d2b42ec`, its pre-patch tip, and `5dc662e` reached `main` later via **#36**. ## Summary

Three commits, all documentation, on one thread: **which claims this repo makes about itself had gone stale.**

1. **`702171f` — correct the mirror-back scope.** `00-shared-research-standards.md` claimed prompts `01` through `12` were all mirrored from the attached Claude project. False for six of them, and self-inflicted: PR #29 widened the original, correct `01`–`05` during a docs sweep without checking what the project actually contains. Corrected to the real scope — `00`–`06` have a canonical project copy; `07`–`12` do not and exist nowhere else. `CLAUDE.md` carried the same over-broad claim in two places and is scoped to match. The corrected paragraph states that it was wrong and why, rather than quietly reading as though it had always been right.

2. **`4dc182c` — record the mirror-back manifest.** A per-prompt table of what needed syncing back to the project, with each row's action inferred from that prompt's commit count since the initial import.

3. **`d2b42ec` — annotate the maturation plan's stale Phase-0 items.** `claude/10-architecture-maturation-plan.md` referenced `PORTING.md`, `scripts/local_ci.sh`, `.gitattributes`, `claude/adr/` and others in present tense ("see `PORTING.md`") when none of them exist — they are things the plan *creates*. Now stated as deliverables, so a reader stops hunting for files that were never written.

No code changed. Full suite 236 passing, 6 intentional skips — unchanged, as expected for a documentation-only PR.

## What this PR did *not* include

The mirror-back was **not executed here**. `4dc182c`'s manifest inferred each prompt's action from commit counts — a proxy for divergence rather than the fact — and it is wrong in two rows: `02` was already byte-identical and needed no overwrite, and `05` was two revisions behind rather than one. That was established by a content diff *after* this PR opened, and did not make it in before the merge.

The execution, and the correction of those two rows, landed separately as **#36** (`a62a99c`). So the manifest table shipped from this PR with both errors intact. See `claude/session-log.md`'s entry for the mirror-back execution.
