# API on 2026-07-24, not a blog post). Its C901 complexity rule is enabled in
# .ruff.toml but is NOT the ratchet -- see scripts/check_code_quality.py,
# which owns the committed per-function baseline ruff has no equivalent for.
ruff~=0.16.0
